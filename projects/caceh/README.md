# projects/caceh

Módulo específico del proyecto **CACEH**: el bot de WhatsApp que llena contratos modelo de trabajo del hogar. Aislado a propósito para poder extraerse como plugin sin desenredarlo del motor.

El diseño, las decisiones y las tareas de este proyecto no viven aquí: viven en el repo `bot_caceh`, en `~/dev/yeeko/bot_caceh/docs/` (arquitectura del módulo, seed, pruebas, infraestructura y canónicos de dominio).
